# Postman / newman

| File | Purpose |
|------|---------|
| `CONIME_Backend.postman_collection.json` | 62 requests in 12 folders, generated by `scripts/generate-postman.ts` from `openapi/openapi.yaml`. Every request tests status codes, `X-Request-Id`, the response JSON Schema, or the error envelope and code |
| `local.postman_environment.json` | Linux dev server (`scripts/dev-api.sh`) with seeded users |
| `staging.postman_environment.example.json` | Template. Copy to `staging.postman_environment.json` (git-ignored) and fill in values locally |

## Tokens

- **Local** (`auth_mode = local_jwt`): the collection's pre-request script mints short-lived HS256 tokens for the seeded users with `local_jwt_secret`. That secret exists only in the local dev configuration (`.env.example`); it is not a real project secret and must never be set to one.
- **Staging** (`auth_mode = supabase`): the pre-request script signs in each test account with `POST {supabase_url}/auth/v1/token?grant_type=password` and caches the access token until shortly before `expires_at`. Fill in `supabase_url`, `supabase_anon_key` (publishable key; safe for clients) and `test_password` in your local copy only. Seeded staging accounts are `userNNN@conime.test`. Rotate the password after hand-over.
- To use a token manually in Postman: run any request once, then copy `token_alice` from the collection variables (Variables tab).

## Run

```bash
scripts/db-local.sh reset --seed && scripts/dev-api.sh &      # local backend
npx newman run postman/CONIME_Backend.postman_collection.json -e postman/local.postman_environment.json
npx newman run postman/CONIME_Backend.postman_collection.json -e postman/staging.postman_environment.json
```

The collection can be re-run against the same data, apart from the last folder "99 Destructive", which deletes one test account (re-seed to repeat). Locally, the diagnosis rate limit is relaxed in `supabase/seed/00_settings_local.sql`. Against staging the default (5 per hour) applies, so wait or use another account when re-running often.

Regenerate after contract changes: `deno run -A scripts/generate-postman.ts`.
